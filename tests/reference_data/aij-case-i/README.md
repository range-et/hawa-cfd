# AIJ Case I measured data

Downloaded November 9, 2026 from the published Zenodo record
[10.5281/zenodo.15430018](https://doi.org/10.5281/zenodo.15430018),
resolved version [15430019](https://zenodo.org/records/15430019).
Data collectors: Kondo, Mutou and Hori; editors: Tominaga, Kikumoto and Okaze.
Licensed [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/).
The two CSV files are unmodified. Hawa's parser ignores empty trailing rows.

`AF_caseI.csv` is the measured approach-flow profile. `RS-w_caseI.csv` contains
velocity and turbulent kinetic energy observations. Cube height 0.1 m;
reference speed 1.7 m/s; air viscosity 1.5e-5 m²/s. Report streamwise and vertical
components separately. Some centre-plane lateral values are symmetry assumptions,
not independently measured lateral-velocity validation. No concentration claim.
