Hawa 0.4 preview

The new videos demonstrate responsive search, 3D views, local airfoil data and timed recordings. Version 0.4 is an experimental preview. The earlier package remains available in the 0.3 build log.

Inspect the fields

Show the domain wireframe. Trace 3D tubes. Select pressure, Cp, speed, vorticity or Q. Share blue-green or spectrum colors across planes, contours and surfaces.

Control repeated runs

Hawa Search advances after each completed result. Pause and cancel work at solver checkpoints. Use example 10 for this workflow.

Use local data

Load airfoil coordinates and polars from your files. Generate four-digit NACA sections offline. Build an unswept tapered wing and estimate attached-flow lift and drag.

Test refinement

One experimental fixed 2:1 patch exchanges populations with its parent grid. Compare a uniform fine-grid solution before using the result.

Watch the recorded Tools video and Wake video. Both use actual simulation fields and captions. Earlier walkthroughs are preserved in the 0.3 build log.

Moving surfaces

The 0.4 work also added prescribed translation, rotation and oscillation, time-matched body loads and previews, and complete-cycle search. Examples 17–20 provide the assemblies. These workflows remain available through Grasshopper in 0.5.

Motion is prescribed. This does not provide force-driven body dynamics, free-surface flow or buoyancy.
