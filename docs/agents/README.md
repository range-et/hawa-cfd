# Agent guides

- [Rhino MCP operation](rhino-mcp.md): open and inspect examples, change inputs,
  start and monitor work, pause/cancel, capture results and close owned documents.
- [Example catalogue](../../examples/grasshopper/README.md): choose a definition,
  understand units, and identify the expected outputs and limitations.
- [Plugin reference](../plugin.md): installation, component groups and controls.
- [Moving surfaces](../moving-surfaces-v0.4.md): prescribed motion, body loads,
  cycle objectives and numerical limits.
- [Verification evidence](../verification-motion-v0.4.json): local checks and
  explicit gaps in validation.

The MCP guide assumes Hawa and Rhino MCP are already installed. It describes
operation through Rhino MCP alone. Building or installing a new plugin version
is a separate developer task.
