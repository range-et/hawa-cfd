Title: Hawa: parametric hull search with Galapagos and MPS

Build a constant-volume hull in Grasshopper. Change the bow, stern, and beam / draft controls. Use Galapagos to search the shape space.

Hawa completes a fresh 200-iteration CFD run for each changed candidate. It measures obstacle momentum exchange and averages the final 20 force samples. The numerical engine runs inside Rhino's Python runtime on MPS. The same evaluator also supports CPU and CUDA device selection.

The recorded search completed one population of ten genomes. Reinstating the selected hull reproduced its score. This coarse, fixed-duration demonstration verifies the assembly. It does not establish a resistance improvement for a real boat.

The hull is fully submerged in a viscous demonstration fluid. The model excludes a free surface, waves, buoyancy, and boat motion. The mesh volume stays fixed. Voxel volume changes on the coarse grid.

This video uses captions and actual Rhino captures. It has no audio.
